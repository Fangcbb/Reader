# Reader v3.2.0-preview.2 · 阅读预设与现代界面

Windows x64 便携预览版。下载独立 EXE 可直接运行，或解压 ZIP 后启动 Reader.exe。
EXE 文件版本为 **3.2.0.1**，以便与上一版区分。升级前建议备份现有 `.settings.json` 配置文件。

## 本次更新

- 新增阅读场景预设：命名保存、覆盖、删除和双击应用，整体恢复字体、字号、文字颜色、背景、透明度和排版参数。入口为「更多 → 阅读预设与场景」，或外观设置顶部「阅读预设」。
- 新增软件界面独立明暗主题，右上角太阳／月亮图标快捷切换；设置可自定义浅色背景、深色背景和强调色。不会改变书页背景和文字配色。
- 改进吸管为全屏取色，可从软件外部窗口取色，支持拖放或点击选择，Esc／右键取消并恢复原颜色。
- 重设计主界面工具栏、侧栏、阅读卡片、底部进度和欢迎页；改善设置布局、键盘操作与焦点恢复。
- 保留上一预览版的 EPUB 封面、章节插图、锚点和图文分页优化，以及图片缩放与文字布局修复。

## 验证

发布工作流执行原生 MSVC Release x64 编译、EPUB 打开／翻页与图片检查、主界面操作、
软件外部取色、UI 主题自定义颜色及持久化检查。
阅读预设测试在重启后改变活动字号、文字颜色、背景和行距，再应用保存的预设，确认恢复正确且 UI 主题保持独立。
附件 SHA256SUMS.txt 可校验独立 EXE 和 ZIP 的完整性。

## 已知范围与限制

- 本版仍为预览版，未完成所有设备、高 DPI 和渲染后端的人工验收。
- 预设中的背景图片保存为路径；图片丢失时会询问是否临时使用纯色。单书自动绑定和预设导入／导出尚未实现。
- 尚不支持完整 EPUB CSS 页面还原或独立 SVG 矢量绘制；旧 EPUB 字符偏移书签仍可能因排版变化移动。
- 封面书架、批注导出等属于后续计划，不属于本次发布功能。
