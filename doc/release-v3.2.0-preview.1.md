Reader v3.2.0-preview.1 · 首个 Windows x64 预览包

下载独立 EXE 可直接运行；ZIP 包附带使用说明。EXE 文件版本为 3.2.0.0。

- 优化主界面、设置布局，增加纸感／护眼／夜读主题和实时排版预览。
- 改善 EPUB 2/3 章节锚点、封面、章节海报与插图分页。
- 修复 GDI+ 图片偏移与图片流生命周期，统一等比缩放，避免小图过度放大。
- 改善逐行居中、标题分页和 UTF-16 双字字符绘制。

验证：400 组图片适配检查、32 组 EPUB 集成测试、21 份图片数据解码通过。
Windows 构建与基础 EPUB 打开／翻页检查由本版本的 Actions 工作流执行；
这不替代不同机器、高 DPI、GDI+/Direct2D 后端的完整视觉验收。

已知限制：旧 EPUB 的字符偏移书签可能移动；不支持完整 EPUB CSS 页面还原或
独立 SVG 矢量绘制。此版本以预览版发布，便于收集实际阅读反馈。
