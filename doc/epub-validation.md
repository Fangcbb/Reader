# EPUB 阅读验证结果

验证日期：2026-11-03。

结论：已通过真实 EPUB 压缩包的解析、目录定位、封面／海报提取和分页集成测试。
尚不能宣称 Windows 界面上的最终显示效果已经验证；当前机器为 Linux，没有
MSVC、Wine 或 Windows 桌面，且下载代理连接失败，无法启动实际阅读器。

## 已执行的检查

测试文件由脚本生成，包含真实 ZIP、container.xml、OPF、XHTML、目录及 PNG/JPEG
资源。没有用户提供的实际书籍；结果的适用范围限于以下样本与边界条件。

| EPUB 用例 | 结果 |
| --- | --- |
| EPUB 3：`nav`、`cover-image` 与其他属性组合，目录标签嵌套 span | 通过 |
| EPUB 2：NCX 目录、meta 封面，spine 无 toc 属性 | 通过 |
| Guide 指向 SVG 包装页，再由 xlink:href 引用封面；封面页也在 spine 中 | 通过，封面无重复页 |
| 无封面书籍 | 正文、章节和海报正常解析 |
| 图片缺失 | 通过，正文可继续读取，已有封面保留 |
| 图片路径包含百分号转义空格 | 通过 |
| JPEG 封面 | 通过 |
| OPF 位于压缩包根目录 | 通过 |
| spine 引用的正文文件缺失 | 按预期返回 PARSE_FAIL，不静默漏章 |

8 个有效 EPUB × 4 种排版，共 32 组全部通过：包含小窗口／常规窗口、留白和段距、
章节分页开关、空行压缩开关。每组检查正文存在、目录锚点的实际文字、标题范围、
非线性附录排除、图片独立分页、向前／向后翻页、图片边界不被文本页吞掉、返回页的
文本覆盖，以及关闭插图后阅读位置仍能推进到书尾。文本向后分页按空间重新填充，
可以与前一张向前分页重叠；不要求两种分页起点完全一致。

封面与海报的数据逐字节对照压缩包资源，并用 Pillow 独立解码。21 份提取数据全部
解码成功，宽高符合样本。此结果验证图片数据完整性，不等于验证 Win32 绘制。

上述集成测试还在 AddressSanitizer 和 UndefinedBehaviorSanitizer 下通过；未运行
泄漏检查。原有 XHTML 提取回归测试继续通过，包括 UTF-16 索引、外部实体隔离、
异常 XHTML 回退、段落与换行。

## 本轮发现并修复

关闭 EPUB 插图后，如果书籍最后是纯图片章节，空行压缩会跳过图片占位符，但原
分页结果没有计入已跳过的位置，返回长度为 0，造成翻页无法前进。

`LayoutText::layout` 现在将实际跳过的空行／隐藏图片位置计入分页长度。测试覆盖
插图开关与空行压缩开关的组合，确认位置持续推进且封面始终保留。

## Windows 待验收范围

- 用 MSVC v143 + Windows SDK 构建 Debug x64，并在实际程序中打开 EPUB。
- 检查 Direct2D 与 GDI+ 的封面／海报缩放、宽高比、四边留白及高 DPI 显示。
- 检查章节点击、键盘翻页、连续翻页、设置保存及图片解码失败提示。
- 用用户日常阅读的 EPUB 复测复杂目录、字体和图文组合。

完整 SVG 矢量绘制及 EPUB CSS 页面还原不在本次实现范围内；SVG 包装中引用
PNG/JPEG 的封面已覆盖。测试命令和 Windows 验收步骤见
[tests/README.md](../tests/README.md)。

## 图片与排版渲染优化复测

- 两个渲染后端共用图片适配计算：修复 GDI+ 丢失目标矩形偏移及等比例图片尺寸错误，
  等比居中、保留四边留白，默认不将小图放大超过原始像素尺寸。
- GDI+ 使用镜像边缘采样和高质量像素偏移，且保持内存图片流存活到位图销毁之后；
  这些 Windows 绘制路径已修改，但仍需 Windows 编译和实际显示验收。
- 正文逐行居中；标题不再孤悬已有正文页的底部；UTF-16 代理对作为一个字形单元
  测量、换行与绘制，避免表情／扩展汉字被拆开。尚未实现完整 Unicode 字素簇处理，
  多码位 ZWJ 表情和复杂文字塑形不在本轮验证范围内。
- EPUB 显式连续 br 换行保留，pre 中 CRLF 不再产生双倍换行。

400 组图片适配边界组合与相关定点回归通过。新增的排版检查在生产布局代码的
Debug 断言开启状态下通过；32 组 EPUB 集成测试与 21 份图片解码继续通过，并通过
地址／未定义行为检查。以上仍不等同于 Windows 实际渲染效果已验收。
