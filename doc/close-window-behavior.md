# 关闭窗口与系统托盘

点击主窗口右上角关闭按钮，或使用 Alt+F4，会显示「关闭 Reader」窗口：

- **退出软件**：关闭窗口并结束 Reader 进程。
- **最小化到托盘**：隐藏主窗口，后台继续运行；点击系统托盘中的 Reader 图标恢复窗口。
- **记住选择，下次不再询问**：保存本次选择，重启后仍有效。不勾选时，每次关闭仍会询问。
- 「取消」、Esc 或关闭选择窗口本身：保留主窗口，不保存关闭偏好。

要修改记住的行为，打开 **更多 → 翻页与阅读行为**：
勾选「关闭窗口时询问退出方式」可恢复弹窗；「默认最小化到系统托盘」可修改默认动作。
「更多 → 退出」及托盘菜单的「退出」始终直接退出软件。
旧版本配置没有询问选项时，升级后默认先询问。

托盘图标创建失败时窗口会保持打开并提示，不会隐藏成无法恢复的后台进程。

## 修复说明

此前阅读区的鼠标过滤误拦截标题栏点击，导致关闭按钮无响应。
现在标题栏按钮、移动、缩放及系统菜单交给 Windows 处理；阅读区鼠标翻页逻辑保持独立。

Windows 回归脚本 `scripts/windows-caption-test.ps1` 使用实际鼠标点击标题栏，
覆盖最大化／还原／最小化、关闭选择、取消、两种动作的一次性与记忆行为、
重启持久化、设置恢复询问和旧配置迁移。
